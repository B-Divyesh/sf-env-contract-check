Privacy

Env Contract Check is designed so your environment data never needs to leave your machine.

What we collect

Nothing. The CLI makes no network requests and includes no telemetry. This site uses no analytics, cookies, accounts, forms, or tracking pixels.

The browser demo

Demo input is processed only in your browser. It is not uploaded, logged, or stored in local storage. Closing or refreshing the page discards edits.

Third parties

The deployed site loads its fonts, images, styles, and scripts from the same origin. Following the GitHub link takes you to GitHub under its own privacy policy.

Questions

Open an issue in the public source repository.
