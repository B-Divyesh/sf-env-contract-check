How it works

Check configuration in three steps

  1. 01

    Write a typed contract

    Set required keys, types, bounds, allowed values, and secret handling in TOML.

  2. 02

    Choose the target parser

    Check how Node, Python, or Docker reads quotes, comments, and expansion.

  3. 03

    Stop invalid settings

    Read clear local output or use JSON and exit codes in CI.

Install the CLI

Build one binary from source. Then run the same command on a laptop or in CI.

● ● ●terminal
cargo install --git https://github.com/B-Divyesh/sf-env-contract-check
$ env-contract-check check \
  --contract env.contract.toml \
  --env .env.production \
  --profile docker \
  --deny-warnings
